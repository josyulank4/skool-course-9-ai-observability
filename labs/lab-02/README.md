# Lab 2: The Gap, Measured

The blindspot package's demo as a lab program — it executes `blindspot/baseline.py`'s demo, the same code the Udemy Lesson 5 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-02/demo.py
```

Work at the `lab-02-start` tag; check yourself at the `lab-02` tag. A correct finish prints, first and last:

```
before silent model change: error rate 0.010, p95 latency 1987.0 ms, mean quality 0.850, hallucination rate 0.025
…
blindspot demo complete
```
