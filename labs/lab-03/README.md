The logline package's demo as a lab program — it executes `logline/emit.py`'s demo, the same code the Udemy Lesson 9 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-03/demo.py
```

Work at the `lab-03-start` tag; check yourself at the `lab-03` tag. A correct finish prints, first and last:
