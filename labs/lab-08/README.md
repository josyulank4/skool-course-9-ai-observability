# Lab 8: Hunt the p99

The p99hunt package's demo as a lab program — it executes `p99hunt/profile.py`'s demo, the same code the Udemy Lesson 29 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-08/demo.py
```

Work at the `lab-08-start` tag; check yourself at the `lab-08` tag. A correct finish prints, first and last:

```
requests profiled: 500
…
p99hunt demo complete
```
