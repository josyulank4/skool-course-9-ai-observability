# Lab 9: The Drift Radar

The decayradar package's demo as a lab program — it executes `decayradar/drift.py`'s demo, the same code the Udemy Lesson 33 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-09/demo.py
```

Work at the `lab-09-start` tag; check yourself at the `lab-09` tag. A correct finish prints, first and last:

```
baseline window: mean quality 0.850, hallucination rate 0.025
…
decayradar demo complete
```
