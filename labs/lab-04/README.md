# Lab 4: Build the Span Tree

The traceweave package's demo as a lab program — it executes `traceweave/trace.py`'s demo, the same code the Udemy Lesson 13 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-04/demo.py
```

Work at the `lab-04-start` tag; check yourself at the `lab-04` tag. A correct finish prints, first and last:

```
span agent-request          kind=root      start     0.0 ms  dur 2140.0 ms  ok
…
traceweave demo complete
```
