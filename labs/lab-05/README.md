# Lab 5: Diff the Versions, Catch the Regression

The promptwatch package's demo as a lab program — it executes `promptwatch/registry.py`'s demo, the same code the Udemy Lesson 17 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-05/demo.py
```

Work at the `lab-05-start` tag; check yourself at the `lab-05` tag. A correct finish prints, first and last:

```
prompt diff v3 -> v4:
…
promptwatch demo complete
```
