# Lab 10: Simulate the Pager

The pagewise package's demo as a lab program — it executes `pagewise/alerts.py`'s demo, the same code the Udemy Lesson 37 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-10/demo.py
```

Work at the `lab-10-start` tag; check yourself at the `lab-10` tag. A correct finish prints, first and last:

```
SLO: 0.999 over 1,000,000 monthly requests
…
pagewise demo complete
```
