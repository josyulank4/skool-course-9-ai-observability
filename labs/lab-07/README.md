# Lab 7: The Token Ledger

The tokenledger package's demo as a lab program — it executes `tokenledger/ledger.py`'s demo, the same code the Udemy Lesson 25 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-07/demo.py
```

Work at the `lab-07-start` tag; check yourself at the `lab-07` tag. A correct finish prints, first and last:

```
requests: 240 (base 200 + retries 40)
…
tokenledger demo complete
```
