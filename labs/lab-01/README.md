# Lab 1: Tour the Watchtower

The authored setup lab: one genuine first run across the whole repo — the shared telemetry dataset and one small real check per package family, all computed live by the course's own packages.

Run it from the repository root:

```bash
python3 labs/lab-01/demo.py
```

Work at the `lab-01-start` tag; check yourself at the `lab-01` tag. A correct finish prints, first and last:

```
observability-tour: one dataset, eleven watchers
…
observability-tour demo: OK
```
