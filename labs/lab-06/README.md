# Lab 6: Audit the Judge

The judgeaudit package's demo as a lab program — it executes `judgeaudit/audit.py`'s demo, the same code the Udemy Lesson 21 hands-on session built.

Run it from the repository root:

```bash
python3 labs/lab-06/demo.py
```

Work at the `lab-06-start` tag; check yourself at the `lab-06` tag. A correct finish prints, first and last:

```
a01: human=pass judge=0.91 (pass) words=142 AGREE
…
judgeaudit demo complete
```
